# dsh-liangshen 待修复问题

本文件记录 `packages/dsh-liangshen` 已确认、尚未修复的缺陷。每条记录包含现象、证据与修复方向；修复落地后删除对应条目，并把结论写进该包所属的 Agent Note。

## 熔断缺少升级阶梯

**严重度：低。** 属已知范围克制，记录以免被误读为遗漏。

### 现象

同一会话连续触发熔断时，行为是原样重复：注入同一条熔断消息，停摆信号下再降一次档，不升级。会话失控时 preset 侧不杀会话是刻意约束，但第二次触发是否应把消息收窄为必须立即给出答案，值得评估。

### 修复方向

为熔断增加分级的后续动作（例如第二次触发注入更硬的要求），并明确该升级与「preset 不杀会话」这条边界的关系。
