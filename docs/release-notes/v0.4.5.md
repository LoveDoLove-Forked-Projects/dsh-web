This release turns the task board into a surface that takes in external work: the GitHub integration imports issues as cards with controlled write-back, and the board gains an external-provider extension contract, hand-switched columns, tag management and a per-execution acceptance gate. The skill center aligns with the official skill acceptance and ranking rules, the usage page switches to any retained day, and the plugin manager adds a list-level bulk update toolbar. The four satellite repositories (skin center, pet, community plugin index, preset center) already published `0.4.5`; this repository tags afterwards and the aggregate consumes them by semver.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The optional fields the task board adds (the external-provider contract, the acceptance toggle and the tags) fall back to the previous behaviour when absent, and a retired row is still read harmlessly. The host floor stays at `>=0.2.0-rc.2`, unchanged from `0.4.4`.

### New Features

- [task-board] An external-provider extension contract, so the board takes external sources through one provider surface
- [task-board-github] Import GitHub issues as cards and write back under the configured login
- [task-board-github] Configure the integration from the settings card and from agent tools, with a new unassigned-issue channel
- [task-board-github] Template issue execution prompts with optional AI analysis
- [task-board] Gate goal completion on a per-execution acceptance, with a per-card opt-out
- [task-board] Cards stay scannable on long issue-synced boards, and long descriptions and prompts are clamped in the detail view
- [task-board] A ledger-wide tag manager, and a settings card reworked into collapsed topic cards
- [task-board] An operator can switch any column by hand
- [plugin-manager] A list-level update toolbar with bulk updates and an explicit restart
- [update] An available release names the DSH floor it requires
- [usage] The usage and Token bank cards switch to any retained day
- [market] The editor's picks feature the Xinghai Heart skin
- [settings] Family plugin cards get an identity mark and tighter copy

### Bug Fixes

- [task-board] Recover judge failures with a 16384-token budget, and dispatch the judge through the registration-bound llm call
- [task-board] Render safe Markdown while retaining multi-line cards
- [task-board] Cards without a pinned target inherit the creating session's workspace, and a subtask permission pin the Lead session covers is inherited
- [task-board] Stop re-registering extension tools while shutting down
- [task-board-github] Resolve the credential per pass instead of at activation, heal the poll guard and surface sync health
- [skill-explorer] Align with the official skill acceptance and ranking rules, treat an omitted invocation policy as invocable, and manage the custom roots the provider row declares
- [usage] Price a public holiday at the off-peak row by default, and exclude Chinese public holidays from the DeepSeek peak windows
- [plugin-manager] Give the standalone bundle row its own loader id, and pin an unversioned install spec to the registry latest
- [remote-web-ui] Serialize settings saves, detach the lan-bind write from the settings transaction, and keep rows a YAML writer displaced
- [web-ui-settings] Read declared fields from the live value rather than schema.dict, and serve every sub-namespace one profile row declares
- [market] Refuse a dist comparison whose content is off the pin, and say tryon/ is left as-is when the shell dist is absent
- [scripts] Probe the tar binary for --force-local instead of branching on the platform
- [release] Wait out a staged npm publish instead of failing the run

- [docs] Record the 2026-09-30 through 2026-10-05 release, market and satellite rounds
- [sdk] The official cohort stays `0.2.0-rc.2`, unchanged from `0.4.4`
