本次发布把全家桶迁移到官方 0.1.7-rc.2 cohort，并带来任务看板的子任务与 Agent Team 执行、桌面端移除与卫星仓拆分后的收尾。

> **重要变更**：本版本没有需要手工迁移的插件数据改动，但有两件事要先知道。
> 一是**宿主下限提高到 `0.1.7-rc.2`**：所有家族包声明 `dsh.engines.dsh >=0.1.7-rc.2`，请先升级 DSH 本体再安装或升级本版本。
> 二是**桌面端（Electron 应用及其打包 lane）已从本仓库移除**：桌面场景由官方 DeepSeek Harness 桌面客户端承接，本仓库不再产出桌面安装包。
> 皮肤中心、宠物、社区插件索引与预设中心四个卫星仓从本版本起与本仓发布同一个版本号 `0.4.2`；它们先发布，本仓随后打 tag，聚合包按 semver 消费它们。

### 新功能

- [task-board] 子任务、Agent 工具与 Agent Team 执行：看板支持父子任务与并发级联执行，新增八个模型可调用的看板工具，并支持以 Agent Team 方式执行（由 Host 为每个子任务拉起队友）
- [market] 市场内容改为经卫星仓 submodule 固定内容提交，构建读取 gitlink 指向的目录
- [scripts] `link-profile` 同时链接卫星包到本地 DSH profile

### 修复

- [remote-web-ui] 应用投放的每一类页面都不再落入配对围栏；LAN 必需提示同时指明两处设置位置
- [task-board] 失败的会话复用执行如实记录，并断言固定的 agent preset
- [client] 插件路由按文档相对路径投递，子路径部署不再拼错地址
- [dsh-web-all] 原地重载后家族页签与看板入口保持可用；带壳家族行改为可配置
- [usage] 余额探测限定在自身账号 origin
- [desktop] profile 重播种时保留每个插件的 bundle patch 文件（随桌面端移除一并退役）
- [market] 移除部署 lane 的部署后资产校验；边缘资产状态按实际重复状态判定并重试瞬时状态

### 其他改动

- [preset-center] 改为消费拆出的预设中心包，不再在本仓内置
- [scripts] PR 评审与皮肤/pet 流程指向卫星仓；退掉本仓不再服务的 renderer 路由与皮肤评审 lane
- [ci] 特权 workflow 只在规范仓库运行；路由 glob 与配置文档一致
- [test] 重录当前测试舰队实际测得的覆盖率基线；家族测试环境提供可用的 localStorage
- [docs] 补齐卫星仓关系、四仓措辞与发布准备说明

This release moves the family onto the official 0.1.7-rc.2 cohort and brings task-board subtasks with Agent Team execution, the removal of the desktop app, and the follow-through from the satellite-repository split.

> **Important change**: no manual plugin-data migration is needed, but two things change up front.
> First, the **host floor rises to `0.1.7-rc.2`**: every family package declares `dsh.engines.dsh >=0.1.7-rc.2`, so upgrade DSH itself before installing or updating this version.
> Second, the **Electron desktop application and its packaging lane have been removed from this repository**: desktop use is served by the official DeepSeek Harness desktop client, and this repository no longer produces desktop installers.
> From this release on, the four satellite repositories (skin center, pet, community plugin index, preset center) publish the same version `0.4.2` as this repository. They publish first and this repository tags afterwards, and the aggregate consumes them by semver range.

### New Features

- [task-board] Subtasks, agent tools and Agent Team runs: the board supports parent/child tasks with concurrent cascade execution, adds eight model-facing board tools, and can run a task as an Agent Team (the host spawns a teammate per subtask)
- [market] Market content is pinned through the satellite submodules, and the build reads the directories the gitlinks name
- [scripts] `link-profile` links the satellite packages into the local DSH profile too

### Bug Fixes

- [remote-web-ui] Every application-delivered page stays out of the pairing fence, and the LAN-required hint names both settings locations
- [task-board] Failed session-reuse executions are recorded honestly, and the pinned agent preset is asserted
- [client] Plugin routes post document-relative, so sub-path deployments no longer build the wrong address
- [dsh-web-all] Family surfaces and the board entry survive an in-place reload, and shelled family rows become configurable
- [usage] A provider balance probe is scoped to its own account origin
- [desktop] Every plugin bundle patch file survives a profile reseed (retired together with the desktop app)
- [market] The deploy lane drops its post-deploy asset verification, and the asset sweep judges edge statuses by what the edge repeats and retries transient ones

### Other Changes

- [preset-center] Consumes the extracted preset center package instead of carrying it here
- [scripts] PR review and the skin/pet flows point at the satellite repositories; the renderer route and skin-review lane this repository no longer serves are withdrawn
- [ci] Privileged workflows run only in the canonical repository, and the routing globs match the documented paths
- [test] The coverage baseline is re-recorded from what the current fleet measures, and the family test setups get a usable localStorage
- [docs] The satellite relationship, the four-repository wording and the release-preparation notes are brought up to date
